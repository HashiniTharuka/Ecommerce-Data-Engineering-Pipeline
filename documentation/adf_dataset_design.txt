PHASE 2 – ADF PIPELINE DESIGN

1. PIPELINE DETAILS

Pipeline Name: PL_Ecommerce_Data_Load

Purpose:
Copy E-commerce Orders, Customers and Products data from local CSV files to Azure Data Lake Storage Gen2.

2. SOURCE AND DESTINATION

ACTIVITY 1: Copy_Orders
Source: processed/cleaned_orders.csv
Source Dataset: DS_Orders_Source
Sink Dataset: DS_Orders_Sink
Destination: processed/orders/orders.csv

ACTIVITY 2: Copy_Customers
Source: processed/cleaned_customers.csv
Source Dataset: DS_Customers_Source
Sink Dataset: DS_Customers_Sink
Destination: processed/customers/customers.csv

ACTIVITY 3: Copy_Products
Source: products.csv
Source Dataset: DS_Products_Source
Sink Dataset: DS_Products_Sink
Destination: processed/products/products.csv

Execution Type: Parallel

All three Copy Activities are independent.
No predecessor dependencies are required.
